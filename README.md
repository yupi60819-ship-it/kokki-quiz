# こっきの ぼうけん

199の国・地域を、国旗と音声で楽しく覚える3歳児向け 国旗クイズです。

サイトを開き、「はじめる」をタップすると遊べます。進捗はブラウザごとに保存され、別の端末・ブラウザとは共有されません。

## クレジット・ライセンス

- 音声：**VOICEVOX:春日部つむぎ**（[VOICEVOX](https://voicevox.hiroshiba.jp/)）。VOICEVOX 利用規約・キャラクター利用規約に従います。
- 国旗：[flag-icons](https://github.com/lipis/flag-icons)（MIT）。ライセンス全文は [flags/LICENSE](flags/LICENSE) を参照してください。
- 地図：[Natural Earth](https://www.naturalearthdata.com/)（public domain）／[world-atlas](https://github.com/topojson/world-atlas)（ISC）。
